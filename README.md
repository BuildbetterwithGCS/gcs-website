# GCS Website — General Contractor Solutions LLC

Public website for [General Contractor Solutions LLC (GCS)](https://buildbetterwithgcs.github.io/gcs-website/).

**Tagline:** Building Better Organizations

> GCS turns operations into intelligence, action, and accountability.

---

## Structure

```
gcs-website/
├── index.html          # Main single-page site
├── css/
│   └── styles.css      # All styles — responsive, WCAG-compliant
├── js/
│   └── main.js         # Navigation, form validation, scroll animations
├── assets/             # Images and media (future)
├── _config.yml         # GitHub Pages configuration
├── robots.txt          # Search engine crawl directives
└── sitemap.xml         # XML sitemap for SEO
```

## Sections

- **Hero** — Brand statement and primary CTAs
- **About GCS** — Mission, values, and founder Sam Hurwitz
- **Services** — Six core service offerings
- **Industries** — Six target industry verticals
- **Nexus Platform** — Platform overview and module descriptions
- **Reference Implementations** — Four illustrative operational patterns
- **Contact** — Contact information and inquiry form

## Standards

- HTML5 / CSS3 / Vanilla JavaScript (no framework dependencies)
- Responsive: desktop, tablet, and mobile
- WCAG 2.1 AA accessibility (skip link, ARIA labels, focus management, semantic HTML)
- SEO: meta tags, Open Graph, structured data (JSON-LD), sitemap, robots.txt
- Ready for GitHub Pages

## Deployment

This site is deployed via GitHub Pages from the `main` branch root.

Live URL: `https://buildbetterwithgcs.github.io/gcs-website/`
