# GCS Public Brand Standards

**Status:** CANONICAL PUBLIC BRAND STANDARD  
**Version:** 1.1  
**Date:** August 2026

> This file and the associated assets are intended for a public GitHub repository. Do not add confidential, client-owned, employer-owned, personal, credential, private financial/medical/legal-sensitive, or proprietary information.

## 1. Brand hierarchy

- **GCS** is the primary master brand.
- **Build Better Organizations** is the brand promise/tagline.
- **Black Diamond Standard** is the GCS quality and execution standard. It is not a competing logo and does not mean the website should be black or dark-heavy.
- **Nexus** is the enterprise intelligence platform.
- **Genesis** is the governed execution/orchestration capability.
- **Mission Control** is the decision and execution governance layer.

Canonical hierarchy: **GCS = brand | Build Better Organizations = promise | Black Diamond = standard | Nexus = platform | Genesis = execution/orchestration.**

## 2. Canonical logo

The canonical GCS logo is the approved compass/organizational mark with the GCS wordmark and the tagline **Build Better Organizations**.

Do **not** make `CONSULTING | PLATFORM | GENESIS` part of the permanent master logo. Product/service descriptors may appear separately in layouts, but they are not part of the canonical logo asset. If a platform descriptor is used, use **Nexus** rather than the generic word **Platform**.

Approved public asset variants:

- `assets/gcs-logo-horizontal.svg` - preferred desktop/header lockup.
- `assets/gcs-logo-stacked.svg` - stacked lockup for square/tall spaces.
- `assets/gcs-mark-full-color.svg` - icon/mark only.
- `assets/gcs-mark-monochrome.svg` - navy monochrome mark.
- `assets/gcs-mark-black.svg` - black mark for constrained reproduction.
- `assets/gcs-mark-white.svg` - white mark for dark backgrounds.
- `assets/gcs-logo-horizontal-black.svg` and `assets/gcs-logo-stacked-black.svg` - black lockups.
- `assets/gcs-logo-horizontal-white.svg` and `assets/gcs-logo-stacked-white.svg` - reverse lockups.
- `assets/gcs-logo-horizontal-green.svg` and `assets/gcs-logo-stacked-green.svg` - approved single-color green variants.
- PNG fallbacks are provided beside the SVGs.

SVG is preferred for the public website because it remains sharp across desktop, mobile, high-DPI, and accessibility zoom use cases.

**Vector source note:** the included SVG geometry is a faithful vector reconstruction from the supplied approved raster artwork. If an original designer/source vector becomes available, it should replace the traced geometry after side-by-side visual verification; the brand hierarchy, colors, naming, and usage rules in this standard remain governing.

## 3. Logo rules

- Preserve the approved proportions and geometry.
- Do not stretch, skew, crop, rotate, outline, shadow, or apply arbitrary effects.
- Do not recolor the full-color mark outside the approved variants.
- Do not redraw the canonical logo using substitute shapes or AI-generated reinterpretations.
- Maintain adequate clear space around the mark and wordmark.
- Use the icon-only mark only where the GCS identity is already clear or space is constrained.
- The tagline must remain legible. At very small sizes, use the mark alone rather than rendering an unreadable tagline.

## 4. Color system

| Role | Hex | Use |
|---|---:|---|
| GCS Deep Navy | `#00122B` | primary wordmark, structure, navigation |
| GCS Steel Blue | `#335475` | secondary structure and intelligence |
| GCS Growth Green | `#68981C` | progress, action, positive emphasis |
| GCS Graphite | `#646465` | supporting neutral |
| White | `#FFFFFF` | primary canvas / reverse treatment |
| Soft Neutral | `#F4F6F8` | panels and separation |

The public website should generally use a light, premium enterprise canvas. Black is an accent or reproduction variant, not the default page theme.

## 5. Black Diamond Standard

Retain Black Diamond as the **quality standard** behind GCS. It communicates disciplined execution, clarity, rigor, reliability, and premium customer-facing quality.

Use the phrase selectively where a quality designation adds value. Do not introduce a second master logo or make a black diamond graphic mandatory on every page.

## 6. Public positioning

Primary public positioning:

**GCS turns organizational operations into intelligence, action, and accountability.**

GCS should be presented as an enterprise intelligence company serving the complete organization rather than as only an operations, facilities, municipal, contractor, or AI-bot company.

## 7. Website and product expression

- Public website: **Discover -> Understand -> Explore -> Experience -> Engage**.
- Nexus: **Observe -> Understand -> Decide -> Act -> Measure -> Learn**.
- Genesis: prepares, coordinates, and executes authorized work.
- Mission Control: prioritizes, decides, approves, and monitors.

Use selection-driven navigation, clear interaction states, and responsive layouts. Avoid turning the public website into one long dark scrolling brochure.

## 8. Enterprise and industry expression

Public positioning should show whole-organization coverage including Executive, Finance, Accounting, HR, Operations, Facilities, Safety, Risk, Procurement, Assets, Fleet, Projects, IT/Data, Compliance, Logistics, Warehouse, Inventory, Shipping/Receiving, and Customer/Community functions.

Industry expression should include municipal/local government, K-12, nonprofits, healthcare/hospitals, manufacturing, **Data Centers**, commercial/private enterprise, facilities/property management, and industrial operations. Data Centers are a first-class industry.

## 9. Public GitHub rule

The repository is a publishing surface. Anything committed to source code, comments, Markdown, assets, fixtures, configuration, branches, commits, pull requests, or issues must be treated as public.

- Use synthetic demonstration data unless information is explicitly approved for public release.
- Never commit credentials, secrets, API keys, tokens, private environment values, personal information, customer information, employer-owned information, confidential records, or proprietary materials.
- Keep code comments technical and public-safe.
- Do not copy private Master Plan material verbatim into the public repository. Translate only the minimum necessary concepts into public-safe implementation specifications.
- If sensitive information is found in Git history, flag it as a potential historical exposure. Deleting the current file alone does not remove prior history.

## 10. Synthetic demo rule

All public Nexus demonstrations must be labeled **SYNTHETIC DEMONSTRATION DATA**. Approved demonstration framework names include Northstar Municipality, BrightPath Foundation, Horizon Health Network, Atlas Manufacturing, and Vertex Data Center.

## 11. Release checklist

- [ ] Approved GCS logo asset is used and clearly visible.
- [ ] Tagline reads `Build Better Organizations`.
- [ ] Black Diamond is treated as a quality standard, not a competing brand or mandatory black theme.
- [ ] Canonical logo does not contain `CONSULTING | PLATFORM | GENESIS`.
- [ ] Product descriptors are separate from the master logo.
- [ ] Desktop and mobile layouts are verified.
- [ ] Interactive states are clear and there are no unexplained dead ends.
- [ ] Enterprise-wide and Data Center positioning is represented.
- [ ] Public demo data is synthetic and labeled.
- [ ] Changed public GitHub files contain no sensitive information.
- [ ] Mocked, simulated, implemented, and roadmap capabilities are accurately distinguished.

## 12. Governance

This is the canonical public brand standard until superseded by a later approved version. Material changes to the logo, tagline, primary color system, Black Diamond role, or brand hierarchy require explicit approval before becoming canonical.
